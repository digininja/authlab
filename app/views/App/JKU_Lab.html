JKU (JWK Set URL) Header Injection

The jku header parameter specifies a URL pointing to a JSON Web Key Set (JWKS) containing the public keys used to verify the token signature. If the server fetches keys from arbitrary URLs without enforcing a strict domain allowlist, an attacker can host their own jwks.json file and forge administrative tokens.
