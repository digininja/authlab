JWK (JSON Web Key) Header Injection

The JSON Web Signature (JWS) standard allows tokens to include an embedded public key in the jwk header parameter. If the server verifies tokens using this header without checking against a trusted key store or whitelist, an attacker can embed their own public key and sign with their own private key.
